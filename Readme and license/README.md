# 📋 Консольный менеджер задач (JavaScript)

> Учебный проект, который вырос из консольного скрипта в полноценное приложение с объектами, функциями и фильтрацией.

---

## 🚀 О проекте

Это консольный менеджер задач, написанный на чистом JavaScript.  
Проект создавался в рамках обучения по курсу «Frontend-разработчик» и является первым серьёзным шагом от простых скриптов к структурированному коду.

**Что умеет программа:**
- Добавлять задачи с уникальным ID.
- Показывать все задачи / только выполненные / только активные.
- Отмечать задачи выполненными.
- Удалять задачи.
- Выводить статистику (всего, выполнено, активно).
- Выходить из программы.

---

## 🧠 Что было изучено и применено

- Работа с массивами и объектами.
- Функции (чистые, без побочных эффектов).
- Циклы и условия.
- Ввод/вывод через `prompt` и `console`.
- Фильтрация данных с помощью методов массивов.
- Тернарные операторы и шаблонные строки.
- Структурирование кода через `switch` и отдельные функции.

---

## 🛠️ Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в любом браузере.
3. Нажмите `F12`, чтобы открыть консоль разработчика.
4. Следуйте инструкциям в меню.
